# 画面モック(docs/mocks)

2026-09-26 のセッションで確定した kyurl.link の画面モックです。`docs/architecture.md` 第6.5節・第6.7節の「見た目の基準」として置いています。ブラウザで `index.html` を開くと、すべての画面を一覧から確認できます。

## 位置づけ

- **見た目の基準であり、実装コードではありません。** マークアップは確認用に書いたもので、インラインstyleを多用しています。実装では第6.2節のデザイントークン(3層)と共通部品で組み直してください。
- **拾ってよい情報:** 余白・文字サイズ・文字の太さ・色の値・角丸・影・並び順・文言・状態の出し分け(選択中・無効・エラーなど)
- **そのまま使わないもの:** インラインstyle、クラス名のない構造、ダミーのQR画像(読み取れない擬似的な模様です)、サンプルのデータ(URL・件数・日付)
- **モックと設計書が食い違う場合は、設計書(第6.7節・第7節)を優先します。**

## 実装時の注意

- **フォント:** モックは表示確認のため Google Fonts(Barlow・Noto Sans JP)を読み込んでいますが、実装は第6.6節どおり、日本語はシステムフォント、Barlow は自前配信にしてください。
- **色:** モックの色は、パレット3色(紺 `#2f5a93`・朱 `#d03e2f`・オフホワイト `#f7f5f0`)から派生させた値です。実装では第6.2節の役割トークンを参照してください。
- **スマホ版がない画面:** 第6.5節のスマホ対応のルール(表はカード、入力を伴うダイアログは全画面、短い確認は通常のダイアログ)を当てはめてください。
- **画面どうしのリンク:** 一部のボタンやリンクは、ほかのモックへつながっています(確認用)。
- **サインアップ画面:** 同意チェックとボタンの状態を切り替える小さなスクリプトが入っていますが、モック用です。
